# MIS-NH-Methylation-Analysis
# Methylation in Gallbladder Cancer (GBC)

**Status:** Data repository for manuscript for submission

**Data availability:** Data will be made available on reasonable request

## About
This repository contains methylation data used for differential comparison analyses in our research article on gallbladder cancer (GBC).

## Four Combinations
| Folder | Comparison |
|--------|-----------|
| Combination_1 | Tumor vs. Control |
| Combination_2 | ICPN with invasion vs. Control |
| Combination_3 | Adenocarcinoma vs. Normal |
| Combination_4 | Adenocarcinoma vs. ICPN with invasion |

## Repository Structure
```
MIS-NH-Methylation-Analysis/
├── README.md
├── Combination_1/    # Tumor vs. Control
├── Combination_2/    # ICPN with invasion vs. Control
├── Combination_3/    # Adenocarcinoma vs. Normal
└── Combination_4/    # Adenocarcinoma vs. ICPN with invasion
```

## R Packages Used
Data handling, visualization, and enrichment analyses were performed
using standard R packages: `tidyverse`, `tidyr`, `forcats`, `patchwork`,
`clusterProfiler`, and `org.Hs.eg.db`
